=== auxiliary experiments (run separately, same venv) ===

(1) Soundness of the "scan ALL edges of G with possibly-tentative labels" step
    (shortest_cycle.py:418-430).  500 random weighted graphs, every value the
    scan computes was checked against an explicit reconstruction:
      graphs with a scanned 'cycle' that is NOT a real simple cycle : 0/500
      sota under-reports (gamma < true girth  => UNSOUND)            : 0
      sota over-reports  (gamma > true girth  => missed cycle)       : 29
      sota returns None though a cycle exists                        : 1
    => the scan is ONE-SIDED SOUND.  Reason: relaxation only ever happens out
    of an already-settled u, so delta(v) = delta(pred(v)) + w(pred(v),v) holds
    EXACTLY for every v that has a predecessor, even for v never settled.
    Hence delta(u)+delta(v)+w(u,v)-2*delta(p) is the exact weight of the closed
    walk (tree path p->u) + (u,v) + (tree path v->p), and because p is the LCA
    in a genuine forest with p != u, v, that walk is a simple cycle of >= 3
    vertices.  All errors are one-sided (missed cycles), never phantom ones.

(2) Truncation semantics.  Code settles u iff delta(u) <= gamma_pre/2 where
    gamma_pre is gamma FROZEN at the start of the root search; the manuscript
    settles v only while delta(v) < gamma_live/2 with gamma updated inside the
    while loop.  300 random trials:
      manuscript Q is a subset of code Q in all 300 trials : True
      code Q strictly LARGER                               : 189/300
    => the code's settled set is a superset.  Harmless for correctness
    (more non-tree edges scanned = more cycles found), costly for the
    complexity claim: the gamma/2 cutoff is much weaker than advertised.

(3) Discard-rule trace on the minimal failing example
